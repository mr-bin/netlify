# Как редактировать раздел «Образование»

Всё содержимое раздела «Образование» (таймлайн обучения, список членств,
галерея дипломов) берётся из одного файла — `data/education.yaml`. Чтобы
что-то поменять на сайте, код трогать не нужно — только этот файл (и, для
документов, папку с картинками `assets/documents/`). Сайт пересобирается
и обновляется сам через пару минут после сохранения.

Сам файл `data/education.yaml` уже содержит подробные комментарии на русском
прямо внутри — что означает каждое поле и готовый пример записи для
копирования. Этот документ — более короткая шпаргалка «как сделать
конкретную вещь».


## Как открыть файлы на GitHub

С компьютера:
1. Зайдите на страницу репозитория на github.com.
2. Откройте нужный файл (например, `data/education.yaml`).
3. Нажмите на значок карандаша в правом верхнем углу — «Edit this file».
4. Внесите изменения.
5. Прокрутите вниз, нажмите зелёную кнопку «Commit changes...», затем ещё раз
   «Commit changes» во всплывающем окне.

С телефона (в браузере, не в приложении GitHub) — так же, только карандаш
внизу страницы с файлом (иногда он спрятан за «...»).

Через 1–2 минуты сайт обновится сам — больше ничего нажимать не нужно
(это и есть «публикация» — отдельного шага для Netlify не требуется).


## Как добавить новую запись обучения в таймлайн

1. Откройте `data/education.yaml`, найдите раздел `timeline:`.
2. Скопируйте один блок записи целиком, например:
   ```yaml
   - year: "2027"
     title: "Название программы"
     hours: "72 ч"
     author: ""
     show: true
   ```
3. Вставьте копию в конец списка `timeline` (или в любое место — порядок
   записей на сайте = порядок в файле) и поменяйте текст.
4. Если часы или автор/организация не нужны — оставьте `""`.
5. Сохраните и опубликуйте (см. выше).


## Как добавить новый документ (диплом/сертификат)

1. Сфотографируйте или отсканируйте документ.
2. **Перед сохранением скройте/замажьте на фото регистрационные и серийные
   номера.**
3. Сохраните картинку в формате JPG, по длинной стороне примерно
   1200–2000&nbsp;px, весом желательно не больше 2–3&nbsp;МБ — пережимать
   точнее и делать отдельную маленькую копию для плитки на странице не нужно,
   сайт сам всё уменьшит при сборке.
4. Положите файл в папку `assets/documents/` в репозитории (загрузить файл на
   GitHub можно через кнопку «Add file → Upload files» в этой папке).
   Дайте файлу понятное имя латиницей без пробелов, например
   `novoe-udostoverenie.jpg`.
5. В `data/education.yaml`, в разделе `documents:`, добавьте блок:
   ```yaml
   - file: "novoe-udostoverenie.jpg"
     caption: "Название документа, 2027"
     show: true
   ```
   Имя в `file:` должно совпадать с именем загруженного файла (включая
   регистр букв).
6. Сохраните и опубликуйте оба изменения (можно одним коммитом).


## Как скрыть или показать запись

У каждой записи (в таймлайне, в списке членств, у каждого документа) есть
поле `show`. Чтобы скрыть запись — поставьте `show: false`, чтобы снова
показать — `show: true`. Саму запись при этом удалять не нужно, можно
держать её «про запас» (например, диплом, который ещё не получен).


## Как поменять ключевые цифры

Цифры вверху раздела («1600+ часов доп. образования», «390+ часов личной
терапии», «240+ часов супервизий») берутся не из `education.yaml`, а из
отдельного файла `settings.yaml` (раздел `stats:` — `education_hours`,
`therapy_hours`, `supervision_hours`). Меняются там же: открыть файл на
GitHub, поправить число, сохранить, опубликовать.


## Что делать, если после правки блок «Образование» пропал или сломался

Ничего страшного — сайт устроен так, что ошибка в файле не ломает уже
опубликованный сайт: посетители ничего не заметят, сайт просто останется
таким, каким был до вашей правки, пока ошибку не исправят.

Самые частые причины:
- пропущена или лишняя запятая, двоеточие или кавычка;
- в тексте случайно изменились отступы (пробелы в начале строки) — в YAML
  они важны, проще всего скопировать соседний блок и менять только текст
  внутри него, не трогая отступы;
- в `file:` у документа указано не то имя файла, что реально загружено в
  `assets/documents/` (или оно не загружено вовсе).

Как посмотреть, в чём именно ошибка:
1. Зайдите на app.netlify.com, откройте сайт (проект).
2. Откройте раздел «Deploys» — там будет свежая попытка сборки с красным
   крестиком и пометкой «Failed».
3. Нажмите на неё, откроется журнал сборки — в конце будет строчка вида
   «ОШИБКА в data/education.yaml: ...» — там по-русски написано, в какой
   записи и что именно не так.
4. Вернитесь на GitHub, исправьте это место, снова сохраните — сайт
   пересоберётся заново.

Если не получается разобраться — пришлите текст этой ошибки из Netlify (или
в следующий чат с Claude), и её можно будет быстро поправить.
