# Как редактировать раздел «Материалы»

Всё содержимое раздела «Материалы» (PDF-листы для скачивания) берётся из
одного файла — `data/materials.yaml`. Чтобы что-то поменять на сайте, код
трогать не нужно — только этот файл (и папку с самими PDF `assets/materials/`).
Сайт пересобирается и обновляется сам через пару минут после сохранения.

Сам файл `data/materials.yaml` уже содержит подробные комментарии на русском
прямо внутри — что означает каждое поле и готовый пример записи для
копирования. Этот документ — более короткая шпаргалка «как сделать
конкретную вещь». Как открыть файлы на GitHub (с компьютера и с телефона) —
см. `education_readme.md`, раздел «Как открыть файлы на GitHub» — шаги
одинаковые для любого файла в `data/`.


## Как добавить новый материал

1. Положите PDF-файл в папку `assets/materials/` (имя файла — латиницей, без
   пробелов, например `novyy-list.pdf`).
2. Откройте `data/materials.yaml`, скопируйте один блок записи целиком,
   например:
   ```yaml
   - title: "Название материала"
     description: "Короткое описание, одна строка"
     pages: 2
     file: "novyy-list.pdf"
     video_url: ""
     labels:
       - "Лучше узнать себя"
     favorite: false
     show: true
   ```
3. Вставьте копию в конец списка `materials` и поменяйте текст. Порядок
   карточек на сайте = порядок записей в файле.
4. Если к материалу есть видео — впишите ссылку на него в `video_url`, и на
   карточке появится кнопка «Смотреть видео». Если видео пока нет — оставьте
   `video_url: ""`, кнопки просто не будет (появится сама, когда ссылку
   впишете). Метку «С видео» дописывать не нужно — она появится сама. Если
   это же видео уже показано в разделе «Видео» на сайте, под ним сама
   появится строка со ссылкой на этот материал.
5. В поле `labels` впишите одну или несколько меток материала — каждая
   должна быть словом в слово такой же, как в списке `labels` в самом начале
   `data/materials.yaml` (см. ниже «Как добавить новую метку»). Если нужной
   метки ещё нет в этом списке — сначала добавьте её туда.
6. Поле `favorite` пока оставляйте `false` — сейчас оно ни на что не влияет,
   подготовлено на будущее.
7. Сохраните и опубликуйте («Commit changes» на GitHub).

На сайте материал будет доступен по адресу вида
`ekaterina-zaikina.page/materials/novyy-list.pdf`, а сама карточка — по
адресу вида `ekaterina-zaikina.page/#list-novyy-list` (id карточки сайт
собирает сам из имени PDF-файла — отдельно его нигде писать не нужно).


## Как добавить новую метку (кнопку-фильтр)

1. Откройте `data/materials.yaml` — в самом начале файла есть список `labels`
   (до раздела `materials`).
2. Допишите новую метку отдельной строкой в этот список — в том порядке, в
   котором хотите видеть кнопки на сайте (кнопка «С видео» добавляется сайтом
   сама и всегда идёт последней, в этот список её писать не нужно).
3. Впишите эту метку в поле `labels` у нужных материалов ниже.
4. Кнопка-метка появляется на сайте, только если у неё есть 2 материала и
   больше — если метка пока только у одного материала, кнопки не будет (она
   появится сама, как только появится второй материал с этой меткой).
5. Если в поле `labels` у материала окажется метка с опечаткой или метка,
   которой нет в списке `labels` в начале файла — сайт всё равно соберётся
   (ничего не сломается), но при сборке будет выведено предупреждение. Если
   сайт собирает для вас Netlify — предупреждение можно увидеть в логе
   сборки на Netlify (Deploys → выбрать сборку → Deploy log).


## Как временно скрыть материал

Поменяйте `show: true` на `show: false` у нужной записи — карточка перестанет
показываться на сайте, сам файл и текст в `data/materials.yaml` останутся на
месте. Чтобы показать её снова — верните `show: true`.


## Как убрать кнопку «Смотреть видео» или добавить её позже

Кнопка появляется сама, если поле `video_url` у записи заполнено, и не
показывается, если оно пустое (`video_url: ""`). Чтобы добавить видео позже —
впишите ссылку в `video_url`, больше ничего менять не нужно.
