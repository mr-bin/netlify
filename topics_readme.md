# Как редактировать тематические страницы

Тематическая страница — отдельная страница сайта про одну тему (например
«Поддержка после потери беременности» на `/poterya-beremennosti/` или
«Бесплодие и диагнозы» на `/besplodie-i-diagnozy/`, «Беременность» на
`/beremennost/`, «ЭКО» на `/eko/`, «Планирование беременности» на
`/planirovanie-beremennosti/`, «Вдали от дома» на `/vdali-ot-doma/`). Каждая такая
страница — это один файл в `data/topics/`. Код трогать не нужно, чтобы
поправить текст или убрать/добавить блок — только этот файл.

Имя файла = адрес страницы: `poterya-beremennosti.yaml` → сайт показывает её
на `/poterya-beremennosti/`. Переименовывать файл после публикации страницы
не нужно — адрес после этого менять нельзя.

Сам файл уже содержит подробные комментарии на русском прямо внутри. Как
открыть файлы на GitHub (с компьютера и с телефона) — см. `education_readme.md`,
раздел «Как открыть файлы на GitHub» — шаги одинаковые для любого файла в `data/`.

## Как поправить текст или скрыть блок

Каждый раздел страницы (`intro`, `topics`, `steps`, `expect`, `medical_note`,
`video`, `faq`) необязателен. Чтобы блок пропал со страницы — удалите его
целиком из файла или оставьте пустым (например `video: {}`). Чтобы блок
«Видео» появился — впишите ссылку на YouTube в `video.url` и название в
`video.title`.

`intro` и `expect` — это один и тот же тип блока («заголовок слева, текст
справа»), просто в разных местах страницы. У обоих есть необязательные поля
`bg` (фон секции: пусто — белый, `sage` — светло-зелёный), `lead` (крупный
вводный абзац шрифтом Alegreya, показывается первым), `highlight` (выделенная
курсивом строка без фона), `items` (компактный список с маркерами сразу после
абзацев — последний абзац становится подводкой к нему, пример — блок «Чего
ждать от работы» на странице «ЭКО»), `callout` (светлая плашка с фоном внутри
блока) и
`footnote` (мелкая серая строка в самом конце блока — например ссылка на
соседнюю тематическую страницу, как на странице «ЭКО»; если строк несколько —
пишите их списком, как на странице «Планирование беременности»).
У `topics` есть необязательное поле `note_style: "box"` — делает плашку под
карточками зелёным прямоугольником (как на странице «Бесплодие и диагнозы»)
вместо курсивной строки без фона (как на странице «Потери беременности»).
`note` под карточками может быть и списком строк — каждая выводится с новой
строки (пример — страница «Вдали от дома»).
У карточки в `topics.items` есть необязательное поле `url` — адрес другой
страницы сайта (например `"/vdali-ot-doma/"`): вся карточка становится
ссылкой, внизу появляется «Подробнее →» (как карточки «С чем можно прийти» на
главной). Пример — последняя карточка на страницах «Планирование
беременности», «ЭКО» и «Беременность». Без `url` карточка обычная.
У `medical_note` есть необязательные поля `intro` (строка перед списком) и
`extra` (строка после списка).
У `zapis` есть необязательное поле `bg: "lavender"` — делает фон блока
«Записаться на консультацию» лавандовым вместо бежевого.

## Ссылки внутри текста и фраза «только когда есть видео»

Ссылку внутри любого текста страницы (абзац, шаг, ответ в FAQ) пишите так:
`[текст ссылки](адрес)`. Например:
`упражнение «[Тёплое одеяло](/#list-teploe-odeyalo)»`. Ссылки на другие
сайты (адрес начинается с `http`) сами открываются в новой вкладке, ссылки
на этот сайт (`/#...`, `#video`) — в той же.

У вопроса в `faq` есть необязательное поле `if_video` — продолжение ответа,
которое появляется на странице, только когда заполнен `video.url` (пример —
в `data/topics/beremennost.yaml`). Ссылка на блок «Видео» этой же страницы —
`(#video)`.

## Ссылки на другое видео (продолжение серии)

Все поля необязательные: пока ссылка пустая (`""`), строки на странице нет.

- В блоке `video`: `more_url` (ссылка на YouTube), `more_title` (название
  видео полностью), `more_lead` (начало строки). Под видео и его описанием
  появляется строка «<more_lead> «<more_title>» →», ссылка открывается в
  новой вкладке. Если `more_lead` не задан, пишется «Продолжение серии — в
  видео». Если нет основного видео (`video.url` пустой), строки тоже нет.
  Пример — `data/topics/besplodie-i-diagnozy.yaml`.
- У вопроса в `faq`: `more_video_url` и `more_video_title`. В конце ответа
  отдельной строкой появляется «Подробнее — в видео «<more_video_title>» →»,
  ссылка открывается в новой вкладке. В отличие от `if_video`, не зависит
  от блока «Видео» на странице. Пример — вопрос «Я пока не уверена, что хочу
  ребёнка…» в `data/topics/planirovanie-beremennosti.yaml`.

## Как добавить новую тематическую страницу

1. Скопируйте `data/topics/poterya-beremennosti.yaml` под новым именем
   латиницей без пробелов (например `eko.yaml`) — это и будет адрес
   страницы (`/eko/`).
2. Отредактируйте текст: `seo` (заголовок и описание для поисковиков),
   `breadcrumb` (название в хлебных крошках), `hero` (первый экран) и
   остальные разделы по образцу.
3. Сохраните («Commit changes») — сайт пересоберётся сам.
4. Чтобы карточка новой темы на главной странице вела на новую страницу
   (как сейчас сделано для «Потери беременности») — это небольшая правка
   кода в `index.html.template`, попросите об этом отдельно.

## Строка-ссылка под шагом (link_line)

У шага в `steps.items` есть необязательное поле `link_line` — строка-ссылка
мелким шрифтом сразу под текстом шага. Пример — шаг 4 на страницах
«Планирование беременности», «ЭКО», «Беременность», «Вдали от дома»:
`link_line: "Все практики и видео о тревоге ожидания&nbsp;— на странице [«Когда тревожно в ожидании»&nbsp;→](/trevoga-v-ozhidanii/)"`.

## Страница-подборка практик (type: practices)

`data/topics/trevoga-v-ozhidanii.yaml` → `/trevoga-v-ozhidanii/` — не обычная
тематическая страница, а подборка практик, видео и листов. У неё своя строка
`type: practices` и свой шаблон (`practices.html.template`), а шапка, первый
экран, блок «Записаться на консультацию» и подвал — общие с тематическими
страницами. Подробная подсказка — в начале самого файла, в том числе как
добавить Short к практике после его выхода (вписать ссылку в `video_url`
нужной практики). Блок листов берётся из `data/materials.yaml` по метке
`sheets.label`. В меню и на главной этой страницы нет — только в sitemap и
по ссылкам с других страниц.

## Строка «Прочитать текстом →» под видео

В блоке `video` необязательное поле `article` — адрес статьи к этому видео
(например `article: "/video/psihosomatika/"`, статьи лежат в `data/video/`,
см. README.md). Под описанием видео появляется строка «Прочитать текстом →»
(та же вкладка). Без `video.url` строки нет. Если статьи с таким адресом нет
(или у неё `show: false`), сборка напишет предупреждение.

Статья к следующему видео (продолжению серии):

- В блоке `video` необязательное поле `more_article` — адрес статьи к видео
  из `more_url`. Под строкой про следующее видео появляется ещё одна
  «Прочитать текстом →» (та же вкладка). Выводится, только если заполнены и
  `more_url`, и `more_article`. Пример — `data/topics/besplodie-i-diagnozy.yaml`.
- У вопроса в `faq`: `more_article_url` и `more_article_title` (название
  статьи = её h1). В конце ответа отдельной строкой появляется «Подробнее — в
  статье «<more_article_title>» →» (та же вкладка); если есть и строка про
  видео — сначала видео, потом статья. Пример — вопрос «Я пока не уверена,
  что хочу ребёнка…» в `data/topics/planirovanie-beremennosti.yaml`.

Если статьи с указанным адресом нет (или у неё `show: false`), сборка
напишет предупреждение.
