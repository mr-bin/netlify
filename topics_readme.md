# Как редактировать тематические страницы

Тематическая страница — отдельная страница сайта про одну тему (например
«Поддержка после потери беременности» на `/poterya-beremennosti/`). Каждая
такая страница — это один файл в `data/topics/`. Код трогать не нужно,
чтобы поправить текст или убрать/добавить блок — только этот файл.

Имя файла = адрес страницы: `poterya-beremennosti.yaml` → сайт показывает её
на `/poterya-beremennosti/`. Переименовывать файл после публикации страницы
не нужно — адрес после этого менять нельзя.

Сам файл уже содержит подробные комментарии на русском прямо внутри. Как
открыть файлы на GitHub (с компьютера и с телефона) — см. `education_readme.md`,
раздел «Как открыть файлы на GitHub» — шаги одинаковые для любого файла в `data/`.

## Как поправить текст или скрыть блок

Каждый раздел страницы (`intro`, `topics`, `steps`, `medical_note`, `video`,
`faq`) необязателен. Чтобы блок пропал со страницы — удалите его целиком из
файла или оставьте пустым (например `video: {}`). Чтобы блок «Видео»
появился — впишите ссылку на YouTube в `video.url` и название в `video.title`.

## Как добавить новую тематическую страницу

1. Скопируйте `data/topics/poterya-beremennosti.yaml` под новым именем
   латиницей без пробелов (например `eko.yaml`) — это и будет адрес
   страницы (`/eko/`).
2. Отредактируйте текст: `seo` (заголовок и описание для поисковиков),
   `breadcrumb` (название в хлебных крошках), `hero` (первый экран) и
   остальные разделы по образцу.
3. Сохраните («Commit changes») — сайт пересоберётся сам.
4. Чтобы карточка новой темы на главной странице вела на новую страницу
   (как сейчас сделано для «Потери беременности») — это небольшая правка
   кода в `index.html.template`, попросите об этом отдельно.
