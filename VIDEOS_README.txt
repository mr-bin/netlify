КАК ДОБАВЛЯТЬ ВИДЕО НА САЙТ
============================

Все видео на сайте (блок «Видео») берутся из одного файла — data/videos.json.
Чтобы добавить, убрать или переставить видео, ничего в коде менять не нужно —
только этот файл. Сайт сам пересоберётся через пару минут после сохранения.


КАК ОТКРЫТЬ ФАЙЛ НА GITHUB
---------------------------

С компьютера:
1. Зайдите на страницу репозитория на github.com (в закладках браузера).
2. Откройте файл data/videos.json (папка data, в ней файл videos.json).
3. Нажмите на значок карандаша в правом верхнем углу — это «Edit this file».
4. Впишите изменения (см. образец ниже).
5. Прокрутите вниз, добавьте короткое описание в поле сообщения (необязательно)
   и нажмите зелёную кнопку «Commit changes...», затем ещё раз «Commit changes»
   во всплывающем окне.

С телефона (в браузере, не в приложении GitHub):
1. Откройте github.com в браузере телефона и войдите в свой аккаунт.
2. Дойдите до файла data/videos.json так же, как описано выше.
3. Внизу страницы с содержимым файла найдите карандаш (иногда нужно нажать
   на «...» или развернуть меню, чтобы его увидеть) — это редактирование.
4. Впишите изменения, прокрутите вниз и нажмите «Commit changes».

Через 1–2 минуты сайт обновится сам — ничего дополнительно нажимать не нужно.


ОБРАЗЕЦ ОДНОЙ СТРОЧКИ ВИДЕО (можно скопировать и поменять текст)
------------------------------------------------------------------

  {
    "url": "СЮДА ССЫЛКУ НА ВИДЕО",
    "title": "СЮДА НАЗВАНИЕ ВИДЕО",
    "note": "",
    "featured": false
  }

Ссылку можно вставлять любую, какую даёт YouTube при нажатии «Поделиться» —
и обычную, и на Shorts, любого вида. Сайт сам разберётся, что это за видео.

Поле "note" — необязательная подпись под названием (например, «Часть 2»).
Если подпись не нужна — оставьте "note": "" как в образце.

Поле "featured" — определяет, главное это видео или нет (подробнее ниже).


КАК ДОБАВИТЬ ВТОРОЕ, ТРЕТЬЕ И ДАЛЬШЕ ВИДЕО — ГДЕ СТАВИТЬ ЗАПЯТУЮ
--------------------------------------------------------------------

Весь файл — это список видео в квадратных скобках, каждое видео — в
фигурных скобках. Между двумя видео (после закрывающей фигурной скобки }
одного видео и перед { следующего) обязательно нужна запятая. После
ПОСЛЕДНЕГО видео в списке запятой быть не должно.

Пример с двумя видео:

  [
    {
      "url": "https://youtu.be/AAAAAAAAAAA",
      "title": "Первое видео",
      "note": "",
      "featured": false
    },
    {
      "url": "https://youtube.com/shorts/BBBBBBBBBBB",
      "title": "Второе видео",
      "note": "",
      "featured": false
    }
  ]

Если добавляете третье видео — скопируйте один блок { ... }, вставьте его
после запятой, и не забудьте поставить запятую после второго блока тоже
(так как теперь он уже не последний).


КАК СДЕЛАТЬ ВИДЕО ГЛАВНЫМ
---------------------------

Главное видео — то самое большое, которое показывается сверху (или слева
на широком экране), остальные — списком под ним.

Чтобы сделать видео главным, поставьте у него "featured": true
(у всех остальных должно остаться "featured": false).

Если ни у одного видео не стоит "featured": true — главным автоматически
становится первое видео в списке.


КАК ПОМЕНЯТЬ ПОРЯДОК ВИДЕО
----------------------------

Порядок видео в списке «Ещё видео» на сайте — точно такой же, как порядок
блоков { ... } в файле. Чтобы поменять порядок — просто переставьте блоки
местами в файле (не забудьте, что запятые должны остаться на своих местах:
между блоками — есть, после последнего блока — нет).


ЧТО БУДЕТ, ЕСЛИ Я ОШИБУСЬ (например, забуду запятую)
-------------------------------------------------------

Ничего страшного не случится. Если в файле ошибка — сайт НЕ обновится и
останется таким, каким был до этого (посетители ничего не заметят).
Ошибка останется только «внутри» — на сайте её не будет видно.

Как посмотреть, в чём именно ошибка:
1. Зайдите на app.netlify.com и войдите в свой аккаунт.
2. Откройте сайт (проект) в списке.
3. Слева или сверху найдите раздел «Deploys» — там будет свежая попытка
   сборки с красным крестиком и пометкой «Failed».
4. Нажмите на неё, откроется журнал (лог) сборки — в конце будет строчка,
   начинающаяся с «ОШИБКА в data/videos.json: ...» — там по-русски
   написано, в каком видео (по счёту) и что именно не так.
5. Вернитесь на GitHub, исправьте это место в файле, снова сохраните —
   сайт пересоберётся заново.

Если не получается разобраться — просто пришлите мне (или в следующий чат
с Claude) текст этой ошибки из Netlify, и её можно будет быстро поправить.
